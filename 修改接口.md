# Bellego 会员管理系统后端修改接口

# 1. 删除接口

* /api/v1/analysis/lifecycle



# 2. 新增接口

### 2.1 指定时间范围内的会员分类

- 路径：GET /api/v1/analysis/category
- 权限：analysis:view

### 描述

* 用于分析模块的“会员生命周期”页面，主要为该页面的饼图使用
* 仅统计**截止月份前（该月最后一天）完成注册**的会员（注册时间 ≤ 截止日期）
* 三个count的和即为截止至目标月份的会员数

### 请求参数

采用**URL 查询参数**传递，无请求体

| 参数名 |  类型  | 是否必填 |    默认值    |                      参数说明                      |
| :----: | :----: | :------: | :----------: | :------------------------------------------------: |
|  date  | String |    否    | 系统当前月份 | 统计截止日期，格式：`yyyy-MM` 不传则默认查全部会员 |

### 返回结构

```json
{
    "code": 200,
    "msg": "操作成功",
    "data": [
        {
            "category": "活跃会员",
            "count": 128
        },
        {
            "category": "沉默会员",
            "count": 56
        },
        {
            "category": "流失会员",
            "count": 32
        }
    ]
}
```

### 2.2 指定时间范围内的会员增长趋势

- 路径：GET /api/v1/analysis/growth
- 权限：analysis:view

### 描述

* 用于分析模块的“会员生命周期”页面，主要为该页面的折线图使用
* 仅统计**指定月份内（date为空则为全部时间段）**的新增会员（注册时间在该月份内）

### 请求参数

采用**URL 查询参数**传递，无请求体

| 参数名 |  类型  | 是否必填 | 默认值 |                      参数说明                      |
| :----: | :----: | :------: | :----: | :------------------------------------------------: |
|  date  | String |    否    |   空   | 统计截止日期，格式：`yyyy-MM` 不传则默认查全部月份 |

### 返回结构

* 如果指定了date，则month均为null，day为该月的日期
* 如果没有指定date，则day均为null，month为月份（yyyy-MM）
